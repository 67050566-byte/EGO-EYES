# 👁️ EGO EYES - Silent Posture Assistant
**"ดวงตาที่สามที่จะคอยเฝ้าระวังหลังของคุณ โดยไม่ขัดจังหวะสมาธิในการทำงาน"**

---

## 1. 🎯 Sprint Goal (Sprint 3)
ใน Sprint 3 ทีมเราจะทำให้ **ระบบฮาร์ดแวร์ EGO EYES สามารถทำงานอ่านค่าระยะและแจ้งเตือนด้วยไฟ Breathing ได้จริง** เพื่อให้ได้ MVP v1 ที่พร้อมนำไปทดสอบระดับการรบกวนสมาธิกับผู้ใช้งานเป้าหมาย

## 2. 🔄 Core Flow
ผู้ใช้ **[เผลอยื่นหน้าเข้าใกล้จอ < 40 cm]** → ระบบ **[ESP32 ประมวลผลและเริ่มจับเวลาหน่วง 10 วินาที]** → ผู้ใช้ **[เห็นไฟ LED แบบ Breathing สว่างขึ้นเตือนสติโดยไม่มีเสียงรบกวน]**
